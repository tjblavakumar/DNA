TECHNOLOGY STACK
================

Backend:
  • Python 3.10+
  • Flask (Web Framework)
  • SQLAlchemy (ORM)
  • Boto3 (AWS SDK)
  • Feedparser (RSS)
  • BeautifulSoup4 (Scraping)
  • ReportLab (PDF)

Frontend:
  • HTML5 + CSS3
  • Bootstrap 5
  • JavaScript
  • Bootstrap Icons

AI/ML:
  • AWS Bedrock
  • Amazon Nova Pro v1:0

Database:
  • SQLite (Development)
  • PostgreSQL/MySQL (Production)

QUICK START COMMANDS
====================

Setup:
  ./setup.sh                        # Automated setup
  python test_setup.py              # Verify setup
  python init_sample_data.py        # Load sample data

Run:
  source venv/bin/activate          # Activate environment
  python app.py                     # Start application

Access:
  http://localhost:5000             # Dashboard
  http://localhost:5000/admin/feeds # Manage feeds
  http://localhost:5000/admin/topics # Manage topics


WORKFLOW
========

1. User clicks "Refresh News"
2. System fetches RSS feeds
3. For each article:
   - Extract content (RSS or scrape)
   - Send to AWS Bedrock for AI analysis
   - Receive summary + topic scores
   - Save if any score > 75
4. Display on dashboard
5. User can export PDF or delete
